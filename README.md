# Telegram App Catalog

Стартовый проект Telegram-бота с Mini App-каталогом и защищённой админ-панелью.

## Что внутри
- Telegram-бот с кнопкой открытия Mini App.
- Каталог с поиском и фильтрацией по категориям.
- Карточки приложений с описанием, рейтингом, размером и ссылкой на официальный источник.
- Админ-панель: добавление, редактирование и удаление карточек.
- SQLite для хранения каталога.
- Загрузка иконок через API предусмотрена; можно также указывать URL изображения.

## Безопасная модель
Проект не запрашивает Apple ID, пароли, коды подтверждения, платежные данные или другие секреты. Ссылки на приложения должны вести на официальные страницы разработчиков или магазинов приложений. Не размещайте чужие учётные записи и не просите пользователей выходить из своих аккаунтов.

## Запуск локально
Нужен Python 3.11+.

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и заполните переменные.
3. Установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
   pip install -r requirements.txt
   ```
4. Запустите:
   ```bash
   python app.py
   ```

Локально веб-сервер доступен на `http://localhost:8000`, но Telegram Mini App требует HTTPS-публичный адрес. Для реального запуска разверните проект на хостинге с HTTPS, затем укажите этот адрес в `WEBAPP_URL` и перезапустите приложение.

## Настройка бота
- В `@BotFather` создайте бота командой `/newbot`.
- Для Mini App установите домен через `/setdomain`, если BotFather предложит.
- В `WEBAPP_URL` укажите полный HTTPS-адрес главной страницы, например `https://catalog.example.com`.
- Токен бота храните только в `.env` на сервере. Не публикуйте его и не отправляйте в чат.

## Админ-панель
Откройте `https://ВАШ-ДОМЕН/admin`. Браузер запросит Basic Auth:
- логин: `ADMIN_USER`
- пароль: `ADMIN_PASSWORD`

Задайте длинный уникальный пароль до публикации проекта. Не используйте значения из примера. Используйте HTTPS.

## Деплой через Docker
```bash
docker build -t telegram-app-catalog .
docker run --env-file .env -p 8000:8000 -v "$(pwd)/catalog-data:/app" telegram-app-catalog
```
Для production настройте HTTPS reverse proxy (например, Caddy или Nginx) перед приложением и постоянное хранилище для `catalog.db` и `static/uploads`.

## API
- `GET /api/apps?q=текст&category=Сервисы`
- `GET /api/categories`
- `POST /api/apps` (Basic Auth)
- `PUT /api/apps/{id}` (Basic Auth)
- `DELETE /api/apps/{id}` (Basic Auth)
- `POST /api/upload` (Basic Auth, PNG/JPG/WEBP до 2 МБ)

Это базовый шаблон. Перед публичным запуском добавьте резервное копирование базы, мониторинг, ограничение частоты запросов и проверку ссылок/загружаемых файлов.
